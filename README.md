# Voltra — releases

Instaladores oficiais do **Voltra**, monitor de consumo real do PC (CPU, GPU e fonte).

Baixe o `voltra-setup-X.Y.Z.exe` da [última release](../../releases/latest) e confira o
`.sha256` publicado junto. O próprio Voltra usa este canal para avisar e instalar atualizações.
